# A run works in steps until done, on the Galaxy A33, 2026-10-18

Ticket #41 of spec #35. A Send now starts a run that asks the model, carries
out each tool call as a builder step, and asks again until the model answers
without a tool call or the person taps Stop. The fixed fix count and per-run
token caps are gone; each request is still checked on its own. Tools:
`list_files`, `read_file` (offset and limit), `search_text`, `write_file`,
`edit_file` (one unique exact old text), `delete_file`, `build`,
`read_build_errors`. Edits stay in a run-owned working copy of the base
revision; `build` and the end of the run commit through the revision-checked
store, and Stop discards uncommitted edits.

## Host tests added

- `StepRunTest` (16) drives the loop with a scripted fake model, the real
  project store and a fake build: first request lists files without contents;
  plain answers; list, read and search; edits stay uncommitted until the end;
  path and manifest refusals; edit needs one unique match; Stop discards
  edits; build commits and offers Install; build errors fixed within the run;
  a failed last build ends without Install; edits after a build are saved;
  stale base refused before any request; stale commit; platform files missing
  ends the run with a tool result and saves the edits; errors name their file.
- `StepProtocolTest` (5): request shape (messages, eight tool schemas,
  `tool_choice` auto, no parallel calls), parsing every tool, refusals without
  echoing arguments, finish reasons and usage, size limits.
- `CompilerDiagnosticsTest` and the worker's `CompileDiagnosticsTest`: the
  numeric diagnostics protocol (version 2) now reports errors in every project
  Java file, so a build error in `Ui.java` names `Ui.java` and its line.

## Not run on a phone, and notes

- Stop during a run. Covered by host tests only; a second paid run was not
  needed for this ticket.
- Android platform files missing. This build used stubs, so the case cannot
  happen on it; host test only.
- Process death during a run. Host tests cover that the journal ends at the
  last committed revision; no phone case (that is #44).
- The model said a display-density helper was missing from "this build
  environment"; that is the stubs, which #38 removes.
- The generated app stays installed after the project's deletion, as the
  delete dialog says.
- Source export still requires exactly two files and refuses larger projects.
- `A33SuiteProbe` now refuses paid models instead of keeping a paid budget.
