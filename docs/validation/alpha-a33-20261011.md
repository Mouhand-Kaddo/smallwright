## Diagnosis and regression

ECJ4.12 canonicalizes compilation-unit filenames (`Main` bytecode shows
`File.getCanonicalPath`). The collector compared those with an absolute, merely
normalized admitted path, losing reports when the source is reached through a
directory alias. A real ECJ regression using a directory symlink returned a null
report before the fix (`alias-regression-red.log` / `.xml`, one test/one failure).
Canonical comparison on both sides fixes the regression while retaining exact
source identity and fail-closed handling of canonicalization failure. Foreign-unit
exclusion, bounded numeric fields, immutable hashes, ECJ's original requestor and
COMPILE_ERROR remain covered. Existing snapshot admission rules are unchanged.
Temporary stage instrumentation was removed; the final original physical runner
passed on the rebuilt, verified APK. Binder remains version1, and detailed numeric
reports are still worker-local; they are not yet integrated into repair previews.
